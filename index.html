Lab manual & explanation

AIM

To implement and compare CPU scheduling algorithms — First Come First Served (FCFS), Shortest Job First (SJF), Round Robin (RR), and Multi-Level Feedback Queue (MLFQ) — using arrival time and CPU burst time.

Procedure

  1. Enter each process ID, arrival time (AT), and burst time (BT).
  2. Select the required scheduling algorithm and set its time quantum if needed.
  3. Click Run Simulation to calculate the execution order.
  4. Observe the Gantt chart and the step-by-step ready queue.
  5. Record completion time (CT), turnaround time (TAT), and waiting time (WT).
  6. Compare average waiting time, average turnaround time, CPU utilization, and throughput.

Formulas: TAT = CT − AT; WT = TAT − BT; CPU utilization = (busy time / total elapsed time) × 100; Throughput = completed processes / total elapsed time.

General scheduling pseudo code

INPUT n processes with AT and BT
FOR each process:
    remaining_time = BT
    completion_time = 0
time = minimum arrival time
WHILE some process is unfinished:
    add all processes with AT <= time to ready set
    choose next process using selected policy
    execute for the policy's time slice
    update remaining_time and time
    IF remaining_time == 0:
        completion_time = time
        turnaround = completion_time - arrival
        waiting = turnaround - burst
DISPLAY Gantt chart and process metrics

Policy: FCFS chooses earliest arrival; SJF chooses the shortest available burst; SRTF chooses the least remaining time; RR rotates processes after a fixed quantum; MLFQ uses priority queues and demotes jobs that consume their time slice.

Reference C program — FCFS

This compact C program demonstrates FCFS calculations. The browser simulator additionally supports SJF, SRTF, RR and MLFQ.

#include <stdio.h>
int main(void) {
    int n, i, j, time = 0;
    int at[20], bt[20], ct[20], tat[20], wt[20];
    printf("Enter number of processes: ");
    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        printf("Enter AT and BT for P%d: ", i + 1);
        scanf("%d%d", &at[i], &bt[i]);
    }
    /* Sort by arrival time (stable for ties). */
    for (i = 0; i < n; i++)
      for (j = i + 1; j < n; j++)
        if (at[j] < at[i]) {
          int t=at[i]; at[i]=at[j]; at[j]=t;
          t=bt[i]; bt[i]=bt[j]; bt[j]=t;
        }
    for (i = 0; i < n; i++) {
        if (time < at[i]) time = at[i];
        time += bt[i];
        ct[i] = time;
        tat[i] = ct[i] - at[i];
        wt[i] = tat[i] - bt[i];
    }
    printf("PID\\tCT\\tTAT\\tWT\\n");
    for (i = 0; i < n; i++)
      printf("P%d\\t%d\\t%d\\t%d\\n", i+1, ct[i], tat[i], wt[i]);
    return 0;
}

Frequently asked questions

1. What is AT? Arrival time — when a process enters the ready queue.

2. What is BT? CPU burst time — total CPU time required by a process.

3. What is CT? Completion time — the time at which a process finishes execution.

4. What is TAT? Total time from arrival to completion: CT − AT.

5. What is WT? Time spent waiting in the ready queue: TAT − BT.

6. Preemptive vs non-preemptive? A preemptive scheduler can interrupt a running process; a non-preemptive scheduler lets it continue until completion.

7. What is the convoy effect? In FCFS, short processes may wait behind one long CPU-bound process.

8. Why use RR? It gives each ready process a time slice, improving responsiveness in time-sharing systems.
